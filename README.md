# Tiny UI Framework

A small browser JavaScript framework built as an engineering learning project. The goal is to understand how framework pieces fit together by implementing them in small phases.

Read [the learning plan](docs/learning-plan.md) for the MVP scope and workflow. The active task is [Phase 3: State updates](docs/phase-3-state-updates.md). Implement its TODOs, then ask for a review before moving on.

The older renderer in `src/framework/render.js` is kept as a reference. The new API starts in `src/framework/h.js`, with DOM creation in `src/framework/dom.js`.
