# 09 — Create a list from data

## The idea

Todo items live as data, but the page needs an `li` element for each item. JavaScript’s `map()` turns every item in an array into a corresponding element description.

## Your task

In `src/main.js`, replace the TODO by setting `children` to the result of mapping `sampleTodos`. For each `todo`, return a description with `type: "li"` and `content: todo`.

## Done when

- The page shows two list items under “A list created from data”.
- You can explain that `map()` turns each string into one element description.
